Open API 对接文档

本节点的实例生命周期管理接口，供商城 / 主控 / 第三方系统对接。所有接口均需鉴权，鉴权方式二选一：

① 请求头携带 X-API-Key（被控 .env 中设置 PANEL_API_KEY 后启用）

② 主控内部调用携带 X-Node-Token（即 NODE_TOKEN，与主控共用）

通用约定
  • Base URL：
  • 请求体为 JSON；错误统一返回 {"detail": "原因"}；鉴权失败 401，实例不存在 404
  • 镜像白名单由 PYTHON_IMAGES / PHP_IMAGES 决定，开通时镜像不在白名单将返回 400
POST/open/provision开通实例（分配端口、创建容器、生成面板令牌）
请求参数
字段类型默认说明
namestring必填实例名称（1-64 字符）
imagestring必填镜像名，如 python:3.12-slim、php:8.3-cli、node:22-slim
daysint30有效期（天），1-3650
cpufloat1.0CPU 核数上限，>0 且 ≤8
memint512内存上限（MB），64-16384
disk_quotaint2048磁盘配额（MB）
start_cmdstring""入口命令，空则按镜像取默认
owner_refstring""归属备注（如商城订单号），便于对账
示例
curl -X POST /open/provision \ -H "X-API-Key: <your-api-key>" -H "Content-Type: application/json" \ -d '{"name":"shop-1001","image":"python:3.12-slim","days":30,"cpu":1,"mem":512,"owner_ref":"order-1001"}'
响应
{ "iid": 12, "name": "shop-1001", "panel_url": "http://<节点地址>:9100/panel?token=...", "panel_token": "<实例面板令牌>", "ext_port": 30124, "expire_at": "2026-10-24T12:00:00", "owner_ref": "order-1001" }
GET/open/instances/{iid}查询实例：状态、配置与实时用量
示例
curl /open/instances/12 -H "X-API-Key: <your-api-key>"
响应（含 provision 全字段，附加）
{ "status": "running", "image": "python:3.12-slim", "cpu_limit": 1.0, "mem_limit": 512, "stats": { "running": true, "cpu_percent": 2.1, "mem_usage_mb": 87, "mem_limit_mb": 512, "mem_percent": 17.0, "net_rx_mb": 12.4, "net_tx_mb": 8.2 } }
POST/open/instances/{iid}/renew续期：在当前到期时间上追加天数
请求参数
字段类型说明
daysint续期天数（1-3650），已过期则从当前时间起算
示例
curl -X POST /open/instances/12/renew \ -H "X-API-Key: <your-api-key>" -H "Content-Type: application/json" -d '{"days":30}' # => {"iid": 12, "expire_at": "2026-11-23T12:00:00"}
POST/open/instances/{iid}/token-reset重置实例面板令牌（旧 panel_url 立即失效）
示例
curl -X POST /open/instances/12/token-reset -H "X-API-Key: <your-api-key>" # => 返回新的 panel_url / panel_token（字段同开通接口）
DELETE/open/instances/{iid}?purge=1回收实例：删容器，联动回收实例数据库；purge=1 时同时删除站点文件
查询参数
参数说明
purge1 = 连同站点目录一起删除；0 = 仅删容器与数据库，文件保留
示例
curl -X DELETE "/open/instances/12?purge=1" -H "X-API-Key: <your-api-key>" # => {"ok": true, "iid": 12, "purged": true}
